# 🎮 Для пользователя

## Что это такое

**World Economic Simulator** — браузерная стратегия, где ты играешь за тайного агента с одной целью: обрушить мировую экономику. Звучит жутковато? Именно так и задумано.

Перед тобой 16 крупнейших экономик мира: США, Китай, Германия, Япония, Россия и другие. Каждая описана реальными макроэкономическими показателями — уровень долга, инфляция, зависимость от импорта энергии, индекс коррупции, золотовалютные резервы, индекс человеческого развития. Все эти данные напрямую влияют на то, какие атаки работают, а какие нет.

Победа достигается только одним способом: снизить среднее экономическое здоровье всех 16 стран ниже 30%. Проиграть тоже несложно: если операцию раскроют и счётчик раскрытия дойдёт до 100%, игра окончена.

Каждая атака в игре основана на реальном экономическом механизме. После каждого хода ты читаешь объяснение, почему именно эта страна была уязвима и как это работает в реальном мире. Это не просто игра — это способ понять, как устроена глобальная экономика.

## Как начать играть

### Шаг 1 — Регистрация

Зайди на [world-economic-simulator-eta.vercel.app](https://world-economic-simulator-eta.vercel.app/), придумай оперативный псевдоним и ключ доступа. Прогресс сохраняется в базе данных, поэтому можно закрыть вкладку и вернуться позже.

### Шаг 2 — Прочти брифинг

После входа откроется окно с инструкцией. На это уйдёт 30 секунд, зато станет понятно, почему одни атаки дают ×2.5, а другие не работают вообще.

### Шаг 3 — Выбери цель на карте

Кликни на страну на интерактивной карте мира. Цвет страны показывает её текущее экономическое здоровье:

| Цвет | Что означает |
|------|--------------|
| 🟢 Тёмно-зелёный | Стабильно (75–100%) |
| 🟡 Оливковый | Лёгкое давление (55–74%) |
| 🟠 Янтарный | Под угрозой (40–54%) |
| 🔴 Тёмно-оранжевый | Опасно (25–39%) |
| ⛔ Красный | Коллапс (0–24%) |

### Шаг 4 — Читай карточку страны

После клика на страну справа появится её профиль:

- **Экономическое здоровье** — сколько осталось до коллапса
- **Долг / ВВП** — ключевой показатель для финансовых атак
- **Резервы** — защита от валютных атак
- **Инфляция и безработица** — горючее для социального взрыва
- **Цифровизация** — уязвимость к кибератакам
- **Энергоимпорт** — зависимость от поставок
- **Коррупция (ИКВ)** — усиливает любой урон
- **Альянсы** — кто защитит страну и как

Внизу карточки — **список уязвимостей**: игра сама подскажет, какая атака подойдёт лучше всего.

### Шаг 5 — Выбери атаку

Открой вкладку **«Арсенал»** и выбери атаку. Для каждой атаки показан множитель эффективности именно против выбранной страны — ищи атаки с `×1.5` и выше.

### Шаг 6 — Бей и следи за волной

После атаки карта оживёт: кризис распространится на торговых партнёров, кредиторов и союзников цели. Удар по одной стране может задеть ещё 3–5 соседей.

## Игровой интерфейс

Интерфейс разбит на четыре вкладки:

### 🗺 Карта
Интерактивная карта мира. Цвет страны — её экономическое здоровье. При атаке страны-жертвы на карте мигают красным.

### 🔗 Связи
Граф экономических связей между странами. Три типа рёбер:
- 🟢 **Торговля** — двунаправленная торговля
- 🔴 **Долг** — стрелка от кредитора к должнику
- 🟠 **Энергия** — стрелка от поставщика к импортёру

Здесь видно, кто с кем связан — это подсказка, куда ударить, чтобы волна прошла максимально далеко.

### 📊 Аналитика
Два интерактивных графика + полная таблица макропоказателей:
- **Динамика здоровья** — линейный график по дням для всех стран
- **Долг vs Здоровье** — пузырьковый скаттерплот: чем выше долг и ниже здоровье, тем слаще цель
- **Таблица показателей** — для каждой из 16 стран: Здоровье, Долг/ВВП, Инфляция, Резервы, Безработица, Цифровизация, Коррупция (ИКВ), ИЧР, Энергоимпорт. Наведи на ячейку — увидишь, как именно показатель влияет на механику атак. Кликни на заголовок — откроется глоссарий с объяснением.

### 📋 Арсенал
Список из 6 атак с кнопкой запуска. Для каждой атаки показана её эффективность против выбранной страны, реальные исторические примеры и экономическое объяснение.

## Атаки

В игре 6 типов экономического оружия, каждое работает по-разному:

### 💸 Валютная атака
**Стоимость:** 120 × вес страны IP | **Урон:** 12 (базовый)

Обрушиваешь курс национальной валюты через скупку/сброс гособлигаций.

| Условие | Множитель урона |
|---------|-----------------|
| Долг >80% ВВП **и** резервы <$200 млрд | **×2.2** |
| Только долг >80% ВВП | **×1.5** |
| Только резервы <$200 млрд | **×1.3** |
| Всё в норме | **×0.4** (почти не работает) |

> 🛡️ Члены **G7** получают экстренную поддержку МВФ — урон ×0.70.

**Реальный пример:** Джордж Сорос сломал британский фунт в 1992 году, заработав $1 млрд за одну ночь. Банк Англии истратил $27 млрд резервов, но проиграл.

---

### 🌀 Долговая спираль
**Стоимость:** 160 × вес страны IP | **Урон:** 16 (базовый)

Провоцируешь рост процентных ставок — страна платит по кредитам всё больше и не может выбраться.

| Условие | Множитель урона |
|---------|-----------------|
| Долг >100% ВВП | **×2.1** |
| Долг 80–100% ВВП | **×1.4** |
| Долг <80% ВВП | **×0.3** (неэффективно) |

> 🛡️ Члены **G7** могут получить антикризисный пакет — урон ×0.72.

**Реальный пример:** Греция 2010 — долг 146% ВВП, ставки взлетели до 25%, ЕС и МВФ выдали кредиты на €300 млрд. Безработица достигла 27%.

---

### 🚫 Торговые санкции
**Стоимость:** 150 × вес страны IP | **Урон:** 14 (базовый)

Отрезаешь страну от главных рынков. Бьёт по странам с концентрированной торговлей.

| Условие | Множитель урона |
|---------|-----------------|
| Зависимость >50% **и** партнёров ≤3 | **×2.7** |
| Только зависимость >50% | **×1.8** |
| Только партнёров ≤3 | **×1.5** |
| Диверсифицированная торговля | **×0.4** |

> 🛡️ Члены **ЕС** перенаправят потоки внутри блока — урон ×0.80. **БРИКС** — ×0.85.

**Реальный пример:** Санкции против России в 2022 — отключение от SWIFT, заморозка $300 млрд резервов. Россия выжила через переориентацию на Китай и Индию.

---

### ⚡ Энергетический шантаж
**Стоимость:** 180 × вес страны IP | **Урон:** 18 (базовый)

Перекрываешь поставки энергии. Работает только против стран-импортёров.

| Условие | Множитель урона |
|---------|-----------------|
| Энергоимпорт >40% | **×2.0** |
| Энергоимпорт <40% | **×0.4** |
| Страна-экспортёр (>40% экспорта) | **×0.2** (бесполезно!) |

> 🛡️ Члены **ЕС** делятся запасами по правилу энергетической солидарности — урон ×0.62.

**Реальный пример:** «Северный поток», 2022 — цена газа в Европе выросла с $200 до $3000 за тыс. кубометров. Германия ушла в рецессию.

---

### 🔥 Социальный взрыв
**Стоимость:** 95 × вес страны IP | **Урон:** 11 (базовый)

Разжигаешь протесты через реальные проблемы населения: инфляцию, безработицу, коррупцию.

| Условие | Множитель урона |
|---------|-----------------|
| Инфляция >8% + безработица >10% + коррупция (ИКВ<35) | **×2.5** |
| Любые два из трёх | **×2.0** |
| Только инфляция >8% | **×1.7** |
| Только безработица >10% | **×1.9** |
| Только высокая коррупция | **×1.5** |
| Всё стабильно | **×0.4** |

> 🛡️ Страны **НАТО** — демократические институты сдерживают протесты (×0.82). **ШОС** — ×0.90.

**Реальный пример:** Чили, 2019 — подорожание метро на 3 цента вывело миллион человек на улицы и привело к смене конституции.

---

### 💻 Кибератака
**Стоимость:** 130 × вес страны IP | **Урон:** 12 (базовый)

Парадокс цифровой эпохи: **чем развитее экономика, тем уязвимее** к кибератакам.

| Условие | Множитель урона |
|---------|-----------------|
| Цифровизация >75% | **×1.9** |
| Цифровизация 55–75% | **×1.0** |
| Цифровизация <55% | **×0.4** (слабо развитая IT) |

> 🛡️ Члены **Five Eyes** делятся разведданными о киберугрозах — урон ×0.38.

**Реальный пример:** Colonial Pipeline, США, 2021 — хакеры остановили крупнейший бензопровод восточного побережья. Компания заплатила $4.4 млн выкупа в биткоинах.

## Система раскрытия

**Раскрытие (0–100%)** — это уровень угрозы провала операции. Если достигнет 100% — игра окончена.

| Ситуация | Изменение раскрытия |
|----------|---------------------|
| Успешная эффективная атака (множитель ≥1.5) | **+3** |
| Успешная стандартная атака | **+6** |
| Успешная неэффективная атака | **+11** |
| Провал атаки | **+15** |
| Цель в защищённом альянсе | **дополнительно +3** |
| Каждый игровой день | **−2** (само спадает) |
| Правильный ответ на квиз | **−10** |

> **Стратегия:** бей точно по уязвимостям — это снижает раскрытие. Жди между атаками, если давление высокое. Отвечай на квизы.

При высоком раскрытии растёт и стоимость атак:
- Раскрытие 40–70%: стоимость +15%
- Раскрытие >70%: стоимость +30%

## Разведка и квизы

Кнопка **«Разведка»** открывает экономический квиз. В день можно ответить на **3 вопроса**, потом система сбрасывается следующим днём.

Вопросы двух типов: одни спрашивают про текущее состояние игры (какая страна сейчас слабейшая? кто больше всего зависит от энергоимпорта?), другие — про реальные экономические механизмы (что такое стагфляция, почему высокий долг опасен, как работает МВФ). Всего в пуле 28 вопросов, и игра следит за тем, чтобы одни и те же не повторялись подряд.

За правильный ответ получаешь **150–200 IP** и **−10 к раскрытию**: считается, что разведка помогла прикрыть следы операции. За неправильный ответ ничего не снимают, но IP не начисляется.

## Стратегические советы

1. **Читай уязвимости** — вкладка с профилем страны сама покажет, какая атака даст максимальный множитель.

2. **Следи за волной заражения** — удари по стране с большим количеством торговых партнёров. Кризис расходится по сети и задевает соседей.

3. **Турция — отличная первая цель**: инфляция 25%, энергоимпорт 70%, коррупция высокая, резервы небольшие. Три атаки — и она в кризисе.

4. **Япония — парадокс**: долг 235% ВВП (рекорд игры!), но огромные резервы ($1.3 трлн) и высокий ИЧР. Долговая спираль + валютная атака работают лучше всего.

5. **Не трогай энергоэкспортёров шантажом** — Россия (60% экспорта), Саудовская Аравия (80%) просто засмеют тебя. Бей их финансово или социально.

6. **Жди между атаками** — раскрытие спадает на 2 в день. Иногда лучше пропустить ход, чем провалить атаку и получить +15.

7. **Квизы каждый день** — 3 вопроса дают до 550–600 IP и снижают раскрытие на 30. Это почти бесплатная атака.

## Игровая механика подробно

### Распространение кризиса

При каждой атаке кризис расходится волной через граф связей:

```
Атака на страну A
    │
    ├── Торговые партнёры → урон × strength × 0.45 (contagion_factor)
    ├── Кредиторы (external_debt_holders) → урон × 0.20
    ├── Энергопоставщики (energy_dependencies) → урон × 0.60
    └── Союзники (alliances) → урон × 0.30
         └── Повторно для каждого затронутого (BFS обход)
```

### Ежедневное обновление (каждые 10 сек реального времени)

```python
if health > 60:   # Активная регенерация
    regen = 3 × trade_bloc_multiplier × hdi_recovery_bonus
elif health > 40: # Медленное восстановление
    regen = 1
elif health > 20: # Стабильный упадок
    damage = 1
else:             # Каскадный коллапс
    damage = 3
```

Торговые блоки ускоряют восстановление (ЕС ×1.5, USMCA ×1.3). ИЧР выше 0.9 даёт +50% к регенерации.

### Условия победы / поражения

| Условие | Результат |
|---------|-----------|
| Среднее здоровье всех 16 стран ≤ 30% | **Победа** |
| Раскрытие достигает 100% | **Поражение** |

### Параметры игрового баланса (`balance.json → global_params`)

| Параметр | Значение |
|----------|----------|
| Порог победы (world_health_threshold) | 30% |
| Стартовые IP | 1000 |
| Ежедневный расход IP | −10 |
| Коэффициент заражения (contagion_factor) | 0.45 |
| Восстановление при health >60 | +3/день |
| Восстановление при health 40–60 | +1/день |
| Спад раскрытия в день | −2 |
| Шанс случайного события | 20% в день |

## API Reference

Базовый URL задаётся переменной окружения `VITE_API_URL`.

| Метод | Маршрут | Тело / Параметры | Описание |
|-------|---------|------------------|----------|
| `POST` | `/register` | `{nickname, password}` | Регистрация нового игрока |
| `POST` | `/login` | `{nickname, password}` | Вход в систему |
| `GET` | `/game/state` | `?nickname=` | Текущее состояние игры |
| `POST` | `/game/attack` | `{nickname, attack_name, target_name}` | Выполнить атаку |
| `POST` | `/game/daily` | `{nickname}` | Тик дня (вызывается автоматически) |
| `GET` | `/game/quiz` | `?nickname=` | Получить вопрос квиза |
| `POST` | `/game/quiz/answer` | `{nickname, answer}` | Ответить на вопрос |
| `POST` | `/reset_game` | `{nickname}` | Сбросить игру |

Пароли хешируются на клиенте через `crypto.subtle.digest("SHA-256")` перед отправкой на сервер, и ещё раз через `hashlib.sha256` на сервере — двойная защита.

## Локальный запуск

### Backend

```bash
cd Backend
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python api_sqlite.py              # запустится на http://localhost:5003
```

### Frontend

```bash
cd Frontend
npm install

# Создай .env.local:
echo "VITE_API_URL=http://localhost:5003" > .env.local

npm run dev                       # запустится на http://localhost:5173
```

### Переменные окружения

| Переменная | Где | Значение |
|-----------|-----|---------|
| `VITE_API_URL` | Frontend `.env.local` | URL бэкенда (для локальной разработки `http://localhost:5003`) |
| `PORT` | Backend (Render) | Порт сервера (по умолчанию 5003) |
