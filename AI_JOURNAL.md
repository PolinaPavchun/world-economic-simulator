# Журнал использования искусственного интеллекта

Архитектура, игровая логика, база данных, серверная часть была спроектирована и написана самостоятельно. ИИ использовался точечно, для ускорения рутинных задач, отладки и генерации вспомогательных элементов (CSS, SVG, тексты).

В процессе работы использовала три разных инструмента на разных этапах.

---

## DeepSeek (начальный этап, без интеграции в код)

На старте использовала DeepSeek в браузере — просто как чат, без подключения к редактору. Помогал разобраться с концепцией и структурой проекта.

| Промпт | Что получила |
|--------|--------------|
| «Как вообще устроена мировая экономика в играх, какие показатели обычно используют?» | Общее понимание какие параметры брать для стран — ВВП, долг, инфляция, резервы. Конкретные числа и структуру придумывала сама. |
| «Объясни как работает эффект заражения в экономике» | Разобралась с идеей распространения кризиса через торговые связи. Механику BFS писала сама. |
| «Какие типы экономических атак бывают в реальности?» | Дал список идей — часть взяла, часть придумала сама, итоговые 6 атак формулировала самостоятельно. |
| «Как хранить состояние игры между сессиями в Python?» | Узнала про SQLite как простой вариант без отдельного сервера. Реализацию писала сама. |
| «Помоги придумать механику раскрытия операции» | Обсудили идею счётчика 0–100%, детали (как растёт, как спадает, что происходит при 100%) придумала сама. |

---

## Cline (средний этап, интеграция в VS Code)

Cline подключён прямо в редакторе, может читать файлы и писать код в проект. Использовала активнее — помогал с конкретными кусками кода.

| Промпт | Что получила |
|--------|--------------|
| «Напиши SQL-схему для таблиц users и game_states» | Сгенерирована структура `CREATE TABLE` в `users_db_sqlite.py`. Функции `add_user`, `check_user` и логику работы с базой писала сама. |
| «Почему CORS-ошибка когда фронт обращается к Flask?» | Объяснил проблему, подсказал `flask-cors`. Строчку `CORS(app)` добавила сама. |
| «Напиши CSS тёмного интерфейса в стиле военного терминала» | Сгенерирована основа `App.css` и `GamePage.css`. Цвета, анимации и вёрстку доделывала вручную. |
| «Как реализовать force-directed граф на SVG без d3?» | Сгенерирован алгоритм физической симуляции — функция `tick` с силами отталкивания и пружинами (строки 100–135 в `ConnectionGraph.jsx`). Фильтры, легенда, боковая панель — писала сама. |
| «Как хешировать пароль прямо в браузере?» | Получила функцию `hashPassword` через Web Crypto API. Решение использовать SHA-256 на клиенте принимала сама. |
| «Как подключить react-svg-worldmap и красить страны?» | Подсказал синтаксис `styleFunction`. Логику цветов по здоровью, выделение выбранной страны писала сама. |
| «Как настроить recharts ScatterChart с референсной линией?» | Синтаксис `<ScatterChart>`, `<ZAxis>`, `<ReferenceLine>`. Идея диаграммы Рейнхарт–Рогофф и смысл осей — самостоятельно. |
| «Подбери реальные данные по ВВП и долгу для нескольких стран» | Проверил порядок цифр для США, Японии, Германии. Структуру balance.json, альянсы, торговые блоки делала сама. |

## Claude Sonnet (финальный этап, интеграция в VS Code)

Ближе к сдаче переключилась на Claude — он лучше справляется с объяснениями и рефакторингом.

| Промпт | Что получила |
|--------|--------------|
| «Как сделать анимированную панель волна кризиса после атаки?» | Идея `animationDelay` через `${i * 100}ms`. Логику заполнения и очистки `crisisSpread` писала сама. |
| «Как сделать заголовки таблицы кликабельными — открывать глоссарий?» | Паттерн `onClick` на `<th>`. Содержание глоссария (8 терминов) писала сама. |
| «Как сделать квиз-модалку которую можно свернуть не теряя вопрос?» | Паттерн `quizMinimized` + плавающий бейдж. Логику блокировки, лимиты попыток писала сама. |
| «Как развернуть Flask на Render с переменной PORT?» | Объяснил `os.environ.get("PORT", 5003)` и `host="0.0.0.0"`. Деплой делала сама. |
| «Проверь формат вопросов квиза» | Проверил структуру словаря. Все 49 вопросов, формулировки, объяснения и исторические примеры — самостоятельно. |
| «Помоги написать структуру для исторических кейсов к атакам» | Предложил формат объекта `REAL_CASES`. Тексты про реальные события писала сама. |
| «Помоги отформатировать README» | Выровнял стиль markdown. Содержание обеих частей README писала сама. |
| «Дополни комментарии в файлах фронтенда» | Дописал комментарии в `ConnectionGraph.jsx`, `GamePage.jsx`. Комментарии в бэкенде писала сама. |

## Что сделано самостоятельно

- Концепция игры и все механики (атаки, распространение кризиса, квиз, раскрытие)
- Классы `Country`, `Attack`, `GlobalEconomyGame` и их методы
- Граф экономических связей и распространение урона по нему
- Механика альянсов и торговых блоков
- Файл `balance.json` — данные по 16 странам
- Образовательные тексты в `lessons.py`
- Реальные кейсы и глоссарий
- Функция `computeAttackConditions` — подсказки по эффективности атак
- Вся игровая логика на бэкенде
- Деплой на Render (бэкенд) и Vercel (фронтенд)
